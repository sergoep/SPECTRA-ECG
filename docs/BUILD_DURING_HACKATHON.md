# What Predated the Hackathon vs What Was Built During It

## Predated the hackathon

-   The spectral-routing research program.
-   Frozen Walsh12 scout architecture and its training on MIT-BIH.
-   Cross-database INCART validation and matched-baseline V5 experiment.
-   V5.2 statistical closure and Zenodo reproducibility archive.

These components provide the frozen scientific substrate. They should
not be represented as having been created during the ten-day event.

## Built during the hackathon

-   Meta Model API / Muse Spark 1.3 integration.
-   ECG image-panel transport to a native multimodal model.
-   Strict structured-output schema for review evidence.
-   FULL / SPECTRA-10 / SPECTRA-20 end-to-end routes.
-   SHA-256-selected Meta demonstration subset.
-   Ground-truth firewall and pre-truth inference seal.
-   API token, latency and cost instrumentation.
-   Cache-safe response logging and failure diagnostics.
-   Locked multimodal experiment and FINAL-X10 audit.
-   Submission/demo packaging.

## Submission wording

Use "built on a frozen pre-existing spectral scout" rather than "we
developed the spectral method during the hackathon."
